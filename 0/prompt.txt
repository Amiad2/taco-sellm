**Logic added to `Persistent`:**
- **`clause_case`** decides whether the rule applies. All of these must hold, otherwise it returns None:
  - the knob is on;
  - `index_clause` is negotiable;
  - the opening's first sheet has a fixed price and no clause;
  - `estimate()` is non-None, which already requires a relationship goal (`RELATIONSHIP_GOALS`) and a priced opening;
  - an own-plant should-cost exists and is at least `value(opening) × (1 − sustainable_margin_pct/100)`. In other words, our own data says a fixed price has no room left.
- **`clause_price`** finds the price where our total cost is lowest, relationship term included. It searches a 601-point grid from 0.85× to 1.0× of the price that pays the supplier exactly its full cost.
- **`clause_sheet`** builds the second offer:
  - our first ask again, with the clause option that costs us least (the widest deadband), at `clause_price`;
  - offered only if it costs us at least 0.2 % less than the fixed price at which the supplier just covers its cost.
- **First e-mail:** carries `[fixed-price ask, clause sheet]` plus one sentence (`CLAUSE_LINE`).
- **Guards:**
  - `structure()`: a clause the supplier prices below `clause_price` is not followed; the agent goes back to the fixed price.
  - `plan()`: our ask on a clause structure is raised to `clause_price`.
  - `plan()`: an open clause offer below `clause_price` sets `enough=False`, so it is not accepted.
- **Tests:** P02 gets the second sheet at the cost-minimal price. P01, P03, P04, P07, P08, P10, P11, P18 and D01 play move for move as before (at least 30 states). The 351.45 clause offer from the clause5-raise session is neither taken nor followed. The agreed clause5-direct sheet is accepted.

- Hand-built clause5-direct @`0fab3fd`: 0.735 at 361.35.
- Lab stress @`a49c9b4`: PASS, 816 negotiations, 56.1 (one loop per thread) / 55.6 (sequential).

**Why it works:** Nordmark's full cost is 367.56, which reproduces both relationship charges exactly. The fixed price of 371.66 at 90 days is its cost floor. A clause buys 5.3 % off the price, but going below about 361 costs more in the relationship term than it saves.

- **CLI wiring:** `arena_kit/cli.py:32` lists `AGENTS = ["naive","llm","sellm"]`. `agent_factory` (`cli.py:49-63`) builds one shared `DataPackage(--data)`, calls `package.lookup("")` to pre-build the ID index, and returns `lambda: make_agent(package)`.
- **Two runners exist.** `arena play` / `arena run` use the kit's `play()` / `play_waves()`: one loop per case, `decide` is called without `focus`. `python -m sellm.runner` is a separate runner (section 7).
- **`make_agent`** (`sellm/agent.py:37-48`):
  - Default: returns `endgame.Persistent(package, writer=SELLM_WRITER or None, **KNOBS)`.
  - With `SELLM_LLM=shadow|apply`: returns `advisor.Advised` instead.
- **`KNOBS`** (`agent.py:11-14`): `past_target=True`, `fast_pay=True`.
- **`CALC_KNOBS`** (`agent.py:19-34`) is dead for the agent. It feeds `sellm.lab.strategies.Calculator`, used only by `experiments/ab_sandbox.py:55-60`, `sellm/lab/__main__.py:52` and `lab/backtest.py`. Keys such as `structure`, `guess_rate`, `steps`, `shape` and `after_final` do not exist in the negotiator.
- **Returned object:** `Persistent` (`endgame.py:65`), a subclass of `Negotiator` (`negotiator.py:175`).
- **`decide(case, threads, focus=None)`** (`negotiator.py:189-201`):
  1. `move()` builds a draft: `{kind: ask|hold|take_alternative|accept|walk_away, sid, sheets, arguments, n, flags}`.
  2. `message()` turns the draft into the API message.
  3. Any exception goes to `rescue()` (`:203-218`). It sends a holding e-mail if more than one move is left, else `closing_move`, else walk away. With `SELLM_STRICT=1` the exception is re-raised instead (tests use this).
  4. `self.fallback = self` (`:183`). The runner's fallback branch requires `fallback is not agent` (`runner.py:228`), so it never fires for sellm.
- **Statelessness:** decisions are recomputed from the threads, except `_memo`, which caches openings, cheapest opening, s0, aim, intel, should-cost and index claims per (case, sid).

## 2. negotiator.py: the per-move procedure

**`Thread` view** (`:121-172`):
- `theirs` / `ours` split the messages; `opening` is the first supplier message with sheets.
- `standing` is the first sheet of its last message; only that one can be accepted (`:151-154`).
- `asks` is the first sheet of each of our messages, so a second "menu" sheet is never counted as our ask.
- `holds` counts our messages that have neither sheets nor an action.
- `left` is `moves_left`.
- `std0` comes from the opening quote PDF. `std = {**std0, **standard_terms(events)}`, i.e. the latest PDF wins.
- `filled()` runs `complete_offer` over std plus the given terms.
- `c()` is `total_cost` with `std`, plus an optional supplier estimate.

**`move()`** (`:221-263`):
1. `live` = threads with a supplier message whose status is not in {walked_away, no_bid}. None live → walk away.
2. Memoised once per case: every opening (fed to the dossier overlay) and the cheapest opening price (the RFQ "market").
3. `cost[sid]` = C of the standing offer, including the relationship term with our estimate (`offer_cost` `:265`). It is inf if there is no sheet ID or a must-have fails. `leader` = lowest cost.
4. `rival[sid]` = cheapest plain C (no relationship term) among the other bidders.
5. `movable` = live threads that are not `ready`, sorted by (number of our asks, cost).
6. With `focus` (per-thread runner):
   - focus is movable → `ask`.
   - Else, if others are still movable → `hold` (needs finite cost, `holds &lt; max_holds`, `left &gt; 1`).
   - Else, once the leader is no longer movable → `close`.
7. Without `focus`: if anything is movable, `ask(movable[0])`; else `close()`.
8. Kit-runner hack (`:255-262`): an accept in a multi-thread case whose thread is not `fresh` sends a `hold` first, so a timeout-replaced offer ID is refreshed before the accept.

**Stop logic:**
- `done` (`:272`): status in (`final_offer`, `agreed`), or `plan.capped` (no visible step left below its price), or `plan.enough` (relationship cases: its offer's C ≤ C at our target).
- `ready` (`:280`): `left &lt;= 0`, or (it has a price and `done` and there is no better alternative sheet).

**Accept / walk** (`close` `:288-301`):
- Accept the takable offer with the lowest C.
- Walk away only if nothing is takable, or the case `alternative` C is below the best offer.
- `final_offer` and `agreed` are always accepted; `push_final` is off.

**Take-alternative** (`:337-354`): once we are done asking, if one of its non-first sheets is valid and at least 0.2 % cheaper and not already sent back, we send it back as our sheet.

**First ask** (`plan` `:357-402`, `aim` `:678-738`):
- Price = `aim.target * (1 - open_below)`.
- Structure = `opening_structure` (section 3).

**Step sizing** (`:383-399`):
- Ceiling:
  - its quoted price on this structure × (1 − `keep_below`);
  - else its standing C converted to a price on our structure (C is linear in price), also capped at its standing price × (1 − `keep_below`);
  - capped again by the rival's C.
- `rounds = max(1, horizon - len(asks))`. If its last body matches `TOO_LOW` (`:86`), rounds = 1.
- `step = (ceiling - last) / (rounds * (1 + pace))`.
- `pace` (`:404-432`) = its concession ÷ ours on an unchanged structure, measured once there are at least 2 rounds, clamped to [0.25, 2]; else the knob value.
- On the same structure the price never goes down. If the structure changed, it can.
- Price is rounded to 2 decimals. `capped` = same structure and no step up is possible.

**Structure after the first reply** (`structure` `:541-565`): we switch to whichever of its quoted sheets (current or opening) has the lowest C, only if the gain is at least 0.2 %. The optional `second_choice` (`:586-606`) is off.

**Term sheets:**
- Each ask sends `[plan sheet]`.
- On the first ask, `menu()` (`:650-665`) adds the same package with the latest payment days at a C-equal price, but only when `cash()` is None, i.e. the dossier coverage is not "full" (a supplier outside the 46 dossiers).
- `message()` (`:850-879`) runs `complete_offer` (exactly the `negotiable` fields), dedupes, checks must-haves and caps at 3 sheets. An ask that ends up with no valid sheet becomes a `hold`.

**Timeouts and round limit:**
- No clock logic lives in the negotiator; the runner handles time.
- Round limit enters only through `left`: `ready` when `left &lt;= 0`; `hold` needs `left &gt; 1`; alternative and push need `left &gt;= 1` and `&gt; 1`.

**E-mail text:**
- `writer.compose` → `template()` (`writer.py:88-130`), fully deterministic. `compose` ignores `chat`, so `writer="llm"` does nothing here.
- Template:
  - greeting: the contact name parsed from the signature, or "Dear Sir or Madam";
  - an opening line (first ask) or "thank you for your reply [and for moving towards us]";
  - optionally "You asked which figures…";
  - the argument sentences;
  - "On that basis we propose {terms}" or "We can improve our proposal to {terms}. Could you meet us there?";
  - sign-off: "Purchasing, Hollerau Pumpenwerke".
- Holds and take-alternative have fixed texts.
- Flag `commitment` is set when our first-ask contract is longer than its own.

**Negotiator knobs** (`negotiator.py:48-68`):

| Knob | Default | What it changes |
|---|---|---|
| `open_below` | 0.06 | first ask = target × (1 − x) |
| `horizon` | 4 | number of our messages in which the two prices should meet |
| `pace` | 0.5 | assumed share of our steps the supplier gives back, until measured |
| `keep_below` | 0.006 | stay at least this share below its price |
| `floor_share` | None | overrides `TARGET_SHARE` {relationship case: 0.945, other: 0.88} (`:75`) |
| `rate_guess` | 0.08 | supplier's cost of money when there is no dossier; `payment_trade` is skipped when the rate equals it |
| `claims` | "bank" | "none" turns arguments off |
| `max_holds` | 2 | holding e-mails per RFQ thread while others are still moving |
| `levers` | "ours" | "theirs" uses its own terms, changed only to cover the need (`:490-500`) |
| `dossier` | True | read sellm.intel |
| `second_choice` | False | see "Structure after the first reply" |
| `recent_cap` | True | cap the prior target at its own 12-month low price |
| `bank` | True | use claims.py when nothing else applies |
| `one_per_topic` | True | one fact per ID prefix (`ctr` counts as `doc`) |
| `ppm` | "plain" | strip the thousands comma before "ppm" (or "skip" / "asis") |
| `signals` | True | dossier signals move the share |
| `writer` | "template" | no effect beyond that |
| `opening_line` | not in DEFAULTS | read at `:316`; overrides the template's first line (wording experiments) |

**Persistence layer knobs** (`endgame.py:46-58`):

| Knob | Default | What it changes |
|---|---|---|
| `past_target` | False (on in KNOBS) | in relationship cases, keep asking past the target while the supplier still moved last round and its offer is above C at `low_target` (full cost × (1 − `estimate_error`), grid search `:208-229`) |
| `estimate_error` | 0.05 | used by `past_target` |
| `past_creep` | None | with `past_target`, limits the step once the target is reached |
| `creep` | None | no step closes more than this share of the gap |
| `zone` / `stall_after` | None / 1 | after it repeats its offer, ask this share below it |
| `push_final` | None | one ask below its first final offer instead of accepting |
| `fast_pay` | False (on in KINOBS) | when the dossier shows `cash_short` or cash pressure medium/high, first ask uses the fastest valid payment days (`:81-93`) |
| `pay_probe` | False | first ask as two sheets that differ only in payment days |
| `signal_facts` | False | a supplier that wants volume hears the forecast first |
| `soft_give` | False | add a non-binding call-off schedule sentence |

## 3. calculator.py

- **`packages(case, standard, price, keep)`** (`:53-64`):
  - cartesian product of `term_options` over the negotiable non-price fields (`structures` `:45`, duplicated at `negotiator.py:96`);
  - `index_clause=None` is kept explicit, meaning a fixed price;
  - `keep` overrides fields;
  - `complete_offer`, then must-haves are checked;
  - sorted by `total_cost(case, terms, standard)`. There is no relationship term here.
- **`price_for`** (`:83`): the price on another structure with equal C (linear inversion). Used by `menu` and `other_payment`.
- **`levers`** (`:67`): only used by the `sheet()` debug printer.
- **How the first-ask terms are picked** (`negotiator.opening_structure` `:446-500`):
  - Its quoted cash terms stay fixed: incoterm, tooling, chargeback, plus payment days unless cash pressure is "low".
  - Everything else (contract_months, volume, effective_date, index_clause, lead time, ppm…) comes from `packages(case, v.std, opening_price × share, keep)`.
  - Among near-ties (≤ 1e-4) it prefers the longest contract, then the closest to its terms.
  - Then `payment_trade` (`:522-539`, only for medium/high cash pressure): days that keep its value equal but cost us ≥ 0.3 % less. `fast_pay` then overrides to the fastest days.
  - Payment days are therefore: latest (C prefers late) for "low", its quoted days for None/medium/high, fastest under `fast_pay`.
- **`supplier_cost(case, sid, events, package)`** (`:130-287`) gives `cost` only for:
  - a case-file `cost:` fact matching the part and the supplier (or no supplier);
  - else the package `should_cost` row of its own plant;
  - else a cost-breakdown XLSX from `events`. The negotiator always passes `events=None` (`:720`, `:745`), so the breakdown is never used.
  - Evidence only (no `cost`): generic should-cost × country factor, `own_low_12m` (flagged if the history says it sold "below full cost"), `rival_low_12m`, `index_justified`.
  - Single-part cases only (`:144`).
- **"Expected end price" = `aim.target`** (`negotiator.py:678-738`):
  - **With an own-plant estimate:**
    1. In relationship cases (goal in {stabilise, secure_supply} with per-point and margin set), the estimate is capped at worth(opening) × (1 − margin%).
    2. `target` = the price that pays exactly its full cost on s0 (supplier_value is linear).
    3. In relationship cases, `target` is instead the grid minimum (251 points between target and max(ref, 1.25 × target)) of C including `relationship_cost`. The supplier estimate there is `{standard: full_standard, interest_rate: dossier cost_of_money or rate_guess, full_cost}`.
  - **Without one (the prior):**
    1. `share` × min(own opening, cheapest opening).
    2. `share()` (`:502-520`): `list_price_fixed ≥ 2` or `margin_floor ≥ 1` → max(base, 0.96); `wants_volume ≥ 2` → min(base, 0.84). Coverage must be "full".
    3. Capped at its recent 12-month low price if `share &lt; 0.96`.
    4. Converted to equal supplier worth on our structure.
    5. `full_cost` is derived from the target, minus a margin adjustment in relationship cases.
  - **Always:** `target ≤ 0.985 × reference`; if not finite, `0.9 × reference`.
- **`estimate()`** (`:749`): the relationship term in `offer_cost` uses `aim.full_cost`. Note the circularity: the target is estimated from the prior.

## 4. claims.py: the argument bank

- **`_Bank(pkg)`** (`:59-94`) indexes `pkg.facts` (facts.json) by prefix and loads cost drivers, should-cost owners, parts, forecast shared flags and letters. It is cached per package (`_bank` `:273`).
- **Builders per fact kind** (`:97-245`):

| Kind | What it says | Counts as helping the buyer when |
|---|---|---|
| `idx` | each driver series over 12 and 6 months, ending at its last month; skipped if that is more than 12 months before the data end | change &lt; −0.5 % |
| `cost` | case estimate, else own plant, else generic; never another plant's | always |
| `sc_otd` / `sc_ppm` | latest scorecard quarter | OTD &lt; 95, ppm &gt; 1000 |
| `qn` | up to 3 complaints within 12 months | ppm ≥ 1000 |
| `po` | first and last order of a part within 24 months | price rose &gt; 0.5 % |
| `fc` | latest forecast | change &gt; 0; private if not shared |
| `news` | about this supplier, excluding noise and market | buyer-side topics; `sensitive` flag set |
| `doc` + `ctr` | a letter's notice days against the contract's | notice shorter than required |
| `quote` | `case_only`; rival quotes are private | always |

- **`citable_for(pkg, sid, parts, case)`** (`:289`): bank entries plus entries from the case's own `facts`.
- **`arguments(case, sid, dossier, package, used, private, price)`** (`:307-345`):
  - merges the dossier's `citable` with `citable_for`;
  - drops entries that do not help us, IDs already used, and private ones;
  - drops `cost`/`quote` at or above the price (cost ≥ 0.98 × price);
  - keeps `case_only` entries only when the case names them;
  - ranks by `ORDER[case.type]` (only quality, capacity and rfq have their own order; price_increase, renewal, bundling and raw_material fall to `DEFAULT_ORDER`), then by strength.
- **How the negotiator picks** (`negotiator.arguments` `:759-781`), one sentence per e-mail, first match wins:
  1. A rival's cheaper standing offer, if not yet cited in this thread.
  2. Own-plant should-cost, if not cited anywhere, price &gt; 1.02 × estimate and our ask ≥ estimate.
  3. `index_claims` (`:816-847`). This duplicates `_idx` but uses `ids[-13]`/`ids[-1]`, with no contiguity or recency check.
  4. `banked` (`:783-814`): skips `quote`, sentences already in the thread, and topics already used.
- **Dedupe:** `cited` = `ID_RE` matches over all our bodies in all threads (`ID_RE` comes from `arena_kit/agents/llm.py:27`).
- **No runtime verification.** Sentences are built from facts.json values. Offline, `tests/test_claims.py:44` runs every statement of the 46 suppliers through `sellm/lab/claims.py:ClaimChecker` and expects zero contradicted.

## 7. runner.py

- **Modes:**
  - `CaseRunner.run` (`:431`) runs one loop per thread when `agent.decide` accepts `focus` (sellm does), else a single loop.
  - **There is no per-case "turns" mode on main.** `docs/STATUS.md:13` says one loop per thread scores 0.665 on P05 against 0.820 for one loop per case. The per-case default lives only on `omars_branch@f60a212`.
- **Waves** (`run_final` `:515-555`): polls `client.cases("final")` every 5 s, starts each open case once (`seconds_left` &gt; 0), follows cap extensions, stops after `waves` closed waves. `run_cases` covers practice and sandbox.
- **Move deadline** (`decide` `:194-246`):
  - the agent runs on a deep copy in a pool; warning at 15 s, hard limit at 40 s;
  - fallback, then a holding e-mail, else `closing_move`;
  - 2 failures in a row → `broken` → close.
- **Clock guard** (`:386-405`): a holding e-mail after 42 s of silence, at most 2 per thread.
- **Re-reads:** after 50 s of silence. The `timeouts[]` of a GET thread are merged as synthetic `from: "timeout@sid"` events (`_merge` `:167-184`).
- **Accept:** waits for in-flight messages (≤ 70 s), re-reads the offer ID and decides again if it changed (`:254-264`). A 409/422 triggers a re-read.
- **Closing before the cap:** `closing_due` (`:187`) at cap − max(90 s, slowest round + 15 s); practice cases stop at 540 s. `finish()` (`:407`) uses `closing_move` with 3 attempts.
- **Resume:** a 409 "one session per case" leads to `resume()` (`:142`). A crash triggers one retry (`play_case` `:474`).
- **Attachments:** waited for at most 20 s (`documents` `:290`).
- **Warm-up** (`:490-512`) is hardcoded to `dossier("sup:70110", ["part:310010"])`.
- **Logging:** `runs/logs/&lt;stamp&gt;-runner-&lt;set&gt;.log` plus a `.jsonl` row per case; `--label` writes `runs/labels.json`.
- **`pull_first`:** yes. `main()` calls `arena_kit.cli.pull_first` (`:627-630`), with `final=True` for the final.
- **Forbidden endpoints:** none touched. Calls are limited to cases, open_session, send_message, thread, session and attachment. `tests/test_runner.py:313` greps runner/negotiator/agent for `/events`, `/screen`, `leaderboard`, `/results`. The `arena board` CLI command does call the leaderboard, but it is outside the agent path.

## 9. arena_kit pieces we rely on

- **`cost.py`:**
  - `closing_terms(case, terms, standard)` layers buyer plan &lt; supplier standard &lt; `fixed_terms` &lt; terms. An unknown incoterm counts as the costliest.
  - `total_cost(case, terms, standard=None, supplier=None)` returns inf without a price and is rounded to 2 decimals. `cost_breakdown` gives the parts (`relationship` included).
  - `supplier_value(case, terms, supplier)` needs `supplier["standard"]` with payment_days and incoterm (else KeyError) and `interest_rate`.
  - `relationship_cost` is 0 unless the goal is in `RELATIONSHIP_GOALS` and a supplier with `full_cost` is passed.
  - `must_haves_ok` fails on None unless the op is `==` or `!=`.
  - `snap` silently returns `options[0]` for a non-numeric value not in the options (index_clause dicts).
  - `complete_offer` fills gaps from the **buyer plan, not the supplier's standard terms**, sets the cheapest-freight incoterm, and rounds the price.
- **`play.py`:**
  - `ENDED = {walked_away, no_bid}`; `final_offer` and `agreed` count as live.
  - `latest()` raises StopIteration if no supplier message exists. `standing(events)`, `live_threads`.
  - `moves_left` counts buyer messages, holds included.
  - `closing_move` uses only `standard_terms(events)` (latest PDF, not std0) and no relationship term.
  - `play()` handles one thread at a time (RFQ clocks can run out); `play_waves` has 90/15 s closing.
  - There is no `pull_first` in `play.py`; it is in `cli.py:35`.
- **`docs.py`:** `quote_terms(text)` → {stated, standard, fixed, agreed} parsed by fixed labels. `standard_terms(events)` reads the latest quote PDF.
